

# Process

1. `<input>` 标签上传文件并获取
2. 将文件切片，并将每片文件计算hash值；（使用 worker 计算，不会阻塞UI）
3. 
    1. 需要将每片hash值组合，在计算出整个file的 hash值；（文件大时，不适合等计算hash完成）
    2. 抽样hash值，计算出一个file的 hash值；
4. 将 file hash值，向后端 api 请求，查看是否有过上传成功的文件切片
    1. 发现[0,5,3]文件切片上传成功，接着上传其他文件切片
    2. 未发现有过上传文件的切片
    3. 已经全部上传完成了，无须上传
5. 前端上传文件切片
6. 文件切片全部上传成功。
